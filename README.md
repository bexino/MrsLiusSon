# Markdown Right-Click Tool

```markdown
`seis`, `siete`.
```

Adds Markdown to the Windows right-click New menu.

---

## Quick Start

[Download the latest release.](https://github.com/bexino/mdKit/releases/)

## Build from Source

```bat
npm install
npm run build
```

### Self-Check

```bat
npm run verify
```
