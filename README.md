# Markdown Right-Click Tool

Adds Markdown to the Windows right-click New menu.

---

## Quick Start

https://github.com/bexino/mdKit/releases/

## Build from Source

```bat
npm install
npm run build
```

### Self-Check

```bat
npm run verify
```
